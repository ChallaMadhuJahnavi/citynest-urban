# 🏙️ CityNest – Urban Settlement Co-Pilot

> A smart platform designed to help newcomers settle into a new city with confidence and ease.

## 📌 About the Project

**CityNest** is an urban settlement platform that brings essential city resources together in one place. It helps newcomers explore housing, discover community activities, access city services, and find wellness resources.

---

# 📄 Pages

The Home Page provides an overview of CityNest and guides users to the main features of the platform.

### Highlights

* Navigation to different sections
* Settlement progress overview

# 🚀 How to Run

### Clone the repository

```bash
git clone https://github.com/ChallaMadhuJahnavi/citynest-urban.git
```

### Open the project

```bash
cd citynest-urban
```

### Run the server

```bash
python server.py
```

Then open the local URL shown by the server in your browser.

---

# 🎯 Project Objective

The main objective of CityNest is to make the process of moving to and settling in a new city easier by providing housing, community, city services, and wellness resources through a single platform.
